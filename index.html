CodeMotion - Animated Code Snippet & Video Generator (MP4 & GIF)

CodeMotion is a free, zero-login, 100% client-side developer tool that converts source code into aesthetic, high-resolution code snippet images (2x/3x Retina DPI), scalable vector SVG graphics, and real-time 60FPS animated typing motion videos (MP4 & GIF).

Core Features & Capabilities

  • 60FPS Real-Time Motion Code Video: Simulate typewriter and line-by-line code animations rendered directly into ISO MP4 video and animated GIF format.
  • VS Code Shiki Syntax Engine: Official TextMate grammars providing exact VS Code syntax highlighting across 30+ programming languages.
  • High-DPI Retina Image Export: Download sharp 2x/3x DPI PNG images or vector SVG graphics for Twitter/X, LinkedIn, technical blogs, and presentation slides.
  • Code Diff Highlighting: Showcase pull requests and refactoring with emerald line addition (+) and rose line deletion (-) badges.
  • Multi-File Window Tabs: Organize complex snippets into window frames with tab switching, title editing, and macOS/Windows control buttons.
  • 100% Local Browser Privacy: Syntax highlighting and video encoding run locally inside your browser. Zero code is uploaded to external servers.
  • LZ Short URL State Sharing: Compress code, tab titles, languages, and theme configurations into ultra-short URL hash links.

Supported Languages & Syntax Color Themes

CodeMotion supports TypeScript, JavaScript, Python, Rust, Go, C++, C#, Java, PHP, HTML, CSS, SCSS, SQL, JSON, YAML, Bash, Dockerfile, GraphQL, Markdown, Swift, Kotlin, Ruby, Elixir, Scala, Haskell, and more.

Available themes include One Dark Pro, Dracula, Tokyo Night, Vercel Dark, Nord, Catppuccin Mocha, Monokai, GitHub Dark, Night Owl, Poimandres, and Light themes.

Frequently Asked Questions (FAQ)

What is CodeMotion?

CodeMotion is a free online tool for software developers, educators, and content creators to turn code snippets into high-resolution images and 60FPS typing motion videos.

How do I export 60FPS code videos?

Paste your code in the CodeMotion Editor, choose your preferred typing speed and format (MP4 or GIF), and click Record Motion Video to download an instant 60FPS animation.

Is CodeMotion free and private?

Yes, CodeMotion is 100% free, open-source, ad-free, and processes code entirely inside your browser with zero remote server transmission.
